# 优秀可视化案例库 — viz-showcase.md

本文件收录各类优秀数据可视化案例，按图表类型分类，供生成可视化时参考。

## 一、趋势类图表

### 1.1 折线图 + 面积填充
**适用场景：** 时间序列、趋势变化、累计增长
**优秀案例特征：**
- 多组对比时使用**不同颜色 + 透明度填充**区域
- **标注关键转折点**（箭头+说明文字）
- X轴标签旋转45°，避免重叠
- 大标题+副标题+数据来源注释

### 1.2 折线图 + 置信区间
**适用场景：** 预测数据、含误差的数据
**优秀案例特征：**
- 使用 `plt.fill_between` 或 seaborn 的 `ci` 参数
- 半透明浅色填充，深色主线条

## 二、比较类图表

### 2.1 分组柱状图
**适用场景：** 多组分类对比、不同年份对比
**优秀案例特征：**
- 使用 **Pastel 色调**（柔和不刺眼）
- 柱顶标注数值
- 同色系不同透明度表示同一维度不同年份
- 横坐标分类名清晰

### 2.2 堆积柱状图
**适用场景：** 构成占比 + 总量对比
**优秀案例特征：**
- 百分比堆积 vs 数值堆积两种形态
- 每段标注百分比
- 图例放在图表右上角或下方

### 2.3 雷达图
**适用场景：** 多维度能力/属性对比
**优秀案例特征：**
- 使用 `pyecharts` 或 `matplotlib` 的 polar 坐标
- 半透明填充 + 实线边框
- 多组对比时不同颜色
- 刻度标注清晰

### 2.4 酷炫雷达图（pyecharts 版本）
适用于**多维度对比 + 网页交互**场景。建议用 `pyecharts` 实现。

## 三、分布类图表

### 3.1 箱线图
**适用场景：** 数据分布、异常值检测
**优秀案例特征：**
- 显示中位数、四分位数、异常值
- 可叠加小提琴图 `violinplot` 展示密度

### 3.2 直方图 + 核密度估计
**适用场景：** 单变量分布
**优秀案例特征：**
- hist 使用半透明色 `alpha=0.6`
- 叠加 KDE 曲线
- 标注均值/中位数竖线

### 3.3 散点图 + 回归线
**适用场景：** 两变量关系、相关性分析
**优秀案例特征：**
- seaborn `lmplot` 或 `regplot`
- 可加 hue 分组着色
- 标注相关系数 R²

## 四、构成类图表

### 4.1 饼图 / 环形图
**适用场景：** 占比构成展示
**优秀案例特征：**
- **尽量不要用饼图**（人眼对角度不敏感）
- 用**环形图**更好，中间可放总数
- 不超过6个切片
- 突出最重要的切片（explode）
- 标注百分比+标签

### 4.2 旭日图（Sunburst）
**适用场景：** 层级数据占比
**优秀案例特征：**
- plotly 的 `sunburst` 或 pyecharts
- 多层嵌套展示层次结构

### 4.3 瀑布图（Waterfall）
**适用场景：** 财务增量分析、累计变化拆解
**优秀案例特征：**
- matplotlib 自定义实现（不同颜色区分增/减）
- 标注每一步的变化值和累计值

## 五、地理类图表

### 5.1 热力图（Heatmap）
**适用场景：** 省份/国家数据分布
**优秀案例特征：**
- pyecharts 地图或 plotly choropleth
- 颜色渐变 + 悬浮数值提示
- 颜色选择蓝-白-红渐变或单色渐变

### 5.2 散点地图
**适用场景：** 地点分布、密度展示
**优秀案例特征：**
- 气泡大小表示数值
- 颜色表示类别

## 六、交互类图表（加分项）

### 6.1 Plotly 交互图
- 鼠标悬浮显示详情
- 可缩放、平移
- 可添加下拉选择器 / 滑动条切换维度

### 6.2 Pyecharts 交互图
- 自适应网页
- 支持鼠标悬停提示、图例开关
- 适合直接嵌入 HTML 报告

## 七、排版设计规范

| 要素 | 推荐设置 |
|------|---------|
| 字体 | **SimHei**（黑体、中文）或系统无衬线 |
| 字号 | 标题 16-18pt，轴标签 10-12pt |
| 配色 | 使用 `seaborn.color_palette("husl", 8)` 或 `Set2` 调色板 |
| 背景 | 纯白底（`#FFFFFF`），网格线浅灰 |
| 图例 | 位置右下或图表上方 |
| 边距 | 上下左右各留 0.5-1cm |
| 格式 | 统一保存为 **300dpi PNG** |
| 水印 | 无，除非作业要求 |
