## 二、训练目标

### 本轮核心目标：L3 稳定虾

让小红在以下方面达到稳定标准：
- [ ] **风格不漂移**：跨会话输出风格一致
- [ ] **交付可预期**：给定同一任务，产出质量稳定
- [ ] **记忆有纪律**：每次重要交互都记录到 memory/
- [ ] **路径清晰**：知道文件在哪里、脚本怎么用、ApiKey 从哪读

### 验收标准
1. 连续 5 次内容生成，风格、质量、格式高度一致
2. 每次训练结束后自动写入 memory/
3. 不需要重复解释"你是谁""你的工具在哪"

## 三、训练轮次设计

### Round 1：风格固化与验收标准建立

**目标：** 明确小红的内容质量标准和验收口径

**动作：**
1. 和我讨论并确认以下内容：
   - 小红的内容风格关键词（活泼？知性？有网感？）
   - 每篇帖子的"最低验收标准"
   - 小刘喜欢和讨厌的风格特点
2. 把这些写入 `IDENTITY.md` 和 `AGENTS.md`

**验收：**
- IDENTITY.md 新增了风格关键词
- AGENTS.md 新增了验收标准
- 双方对"什么叫好的小红书帖"达成共识

### Round 2：跨会话测试

**目标：** 验证风格连续性

**动作：**
1. 小刘在同一主题下连续 3 轮对话，检查输出一致性
2. 中间中断会话后再继续，检查记忆持续能力
3. 跨天测试风格是否漂移

**验收：**
- 同一 prompt 在不同会话输出质量无明显差异
- 不需要重复提醒"你是谁""你的风格是什么"

### Round 3：记忆纪律建立

**目标：** 让 memory 成为训练资产

**动作：**
1. 明确哪些信息需要写入 memory/（用户偏好、决策原则、失败案例）
2. 每次重大交互后自动写入 agents/xiaohongshu/memory/
3. 每周 review MEMORY.md 做 compaction（合并/去重/归档）

**验收：**
- 小刘问"上次那个面霜帖我们怎么写的"能立刻回答
- memory 文件有条理，不是原始日志堆积

### Round 4：内容质量盲测

**目标：** 量化评估输出质量

**动作：**
1. 准备一组测试主题（5个不同方向）
2. 小红产出完整帖子
3. 小刘按验收标准打分
4. 根据反馈调整 prompt 模板和 references/

**验收：**
- 平均分≥4/5
- 最低分不低于3/5
- 无"完全不能用"的输出
