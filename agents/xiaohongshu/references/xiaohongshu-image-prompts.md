# 小红书配图 Prompt 体系（🍒 小红专用）

> 根据文案内容方向自动匹配图片 prompt 风格。
> 配图的灵魂是"小红书调性"——干净、有质感、不影楼风。

---

## 🎨 核心原则

- **真实感 > 完美感** — 像拿手机拍的，不是专业广告片
- **氛围 > 细节** — 先定调（温暖/冷清/复古/清新）
- **比例：** 默认 1024x1024（正方形，小红书最友好）
- **模型选择：** Qwen/Qwen-Image（通用首选）

---

## 📐 内容方向 × 图片风格映射

### 1. 好物推荐 / 测评类 → 静物美学

**风格标签：** `ins风静物`、`奶油色调`、`干净背景`、`自然光`

**构图公式：**
```
[主体] + [场景/背景] + [辅助元素] + [光线] + [色调] + [风格词]
```

**示例 prompt 结构：**
```
产品放在[背景]上，旁边有[装饰元素]，[光线]照射，[色调]调色，
[风格]摄影风格，小红书美学，质感细节清晰
```

## 🤖 Prompt 自动生成规则

当文案产出后，自动根据以下规则生成配图 prompt：

```python
def auto_generate_prompt(content_type, product_name, scene, vibe):
    """
    content_type: recommend | checkin | daily | knowledge
    product_name: 产品/地点名称（可选）
    scene: 场景描述
    vibe: 氛围（温暖/清新/复古/高级）
    """
    style_map = {
        "recommend": "ins风静物摄影，产品特写，干净背景，自然光，小红书美学",
        "checkin": "探店摄影，环境氛围，有生活气息，暖色调，景深感",
        "daily": "日常感，生活化记录，自然光线，平实温馨，真实氛围",
        "knowledge": "简洁清晰，明亮通透，干净构图，教育感，前后对比"
    }
    
    color_map = {
        "温暖": "暖色调，奶油色系",
        "清新": "清新色调，青绿色系，亮调",
        "复古": "胶片感，暖黄调，颗粒感",
        "高级": "冷色调，低饱和，质感光影",
        "活泼": "明亮的色彩，高饱和度，欢快氛围",
    }
    
    prompt = f"{scene}，{product_name + '，' if product_name else ''}"
    prompt += f"{style_map[content_type]}，{color_map.get(vibe, '')}"
    prompt += "，高清，小红书风格，有质感"
    
    return prompt
```

## 🚫 避免的 prompt 问题

| 问题 | 原因 | 改进 |
|------|------|------|
| 太复杂（描述过长的场景） | AI 丢细节 | 聚焦3-5个核心元素 |
| 没有人设感（"画一张…"） | 不像小红书 | 直接用场景描述 |
| 负面词过多（"不要…"） | AI 容易忽略 | 只说想要什么 |
| 抽象概念（"时尚感"） | 太模糊 | 具体到"米白色/极简/剪裁利落" |
| 水印/文字内容 | 图生字不准 | 不加文字，后期排版加 |

> **核心心法：** 一个 prompt 只说一件事，画面越简单越稳。
