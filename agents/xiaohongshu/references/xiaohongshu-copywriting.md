# 小红书文案体系 (小红专用)

> 本指南定义了小红输出文案的风格、结构和模板。
> 所有产出遵循"先读此文，再写文案"原则。

---

## 🎯 核心原则

- **真实感第一** — 像朋友在分享，不是品牌在广告
- **第一人称** — "我"的视角，"我"的体验
- **短句+分段** — 每段不超过 3 行，留白多
- **Emoji 点缀** — 每段 1-2 个，不泛滥
- **数字说话** — 价格、数量、时间，越具体越好

---

## 📐 内容结构模板

### 1. 好物推荐 / 测评类

```
【标题】数字 + 场景 + 效果
        例：用了30天的xx，皮肤真的会说话

【开头】痛点引入 / 场景代入
        "作为一个xx星人，我一直在找…"
        "谁懂啊！这个xx真的绝了…"

【正文】
📦 开箱/第一印象
→ 外观、质感、味道、第一感受

✨ 使用体验（分段写）
→ 每次用都是什么感受
→ 和之前用的对比
→ 意想不到的惊喜点

⚠️ 缺点/注意事项
→ 诚实说问题，增加信任感

【总结】
✅ 什么人适合
✅ 什么场景最好用
✅ 性价比评价

【标签】
#好物推荐 #真实测评 #xx推荐
```

### 2. 探店打卡类

```
【标题】地点 + 亮点 + 推荐理由
        例：藏在胡同里的神仙咖啡馆 ☕

【开头】怎么发现的 / 第一印象
        "路过的时候被门头吸引了…"
        "朋友强推了N次终于来了…"

【正文】
📍 位置和环境
→ 好找吗？氛围怎么样？
→ 适合什么时候来？

🍽️ 点单推荐
→ 点了什么、多少钱
→ 哪个最好吃/最好喝
→ 避雷指南

📸 拍照攻略
→ 哪个角度最好拍
→ 什么时间光线最好

【总结】
🏆 整体评分 / 推荐指数
💰 人均消费
📌 地址 + 营业时间

【标签】
#探店 #xx探店 #周末去哪儿
```

### 3. 日常分享 / Vlog 类

```
【标题】时间 + 活动 + 情绪
        例：周末宅家的一天，治愈到我想哭 🥹

【开头】氛围铺垫
        "最近的天气太适合…"
        "分享一个让我心情变好的小事…"

【正文】
按时间线/活动线串起来
→ 早上干了什么
→ 中午的小确幸
→ 晚上的放松时刻

穿插：
→ 好物种草
→ 心情记录
→ 拍照分享

【结尾】
暖心的总结 + 互动
"你们最近有类似的治愈时刻吗？"

【标签】
#日常 #生活记录 #治愈系
```

### 4. 知识科普 / 教程类

```
【标题】数字 + 知识 + 目标人群
        例：新手必看的5个护肤误区 ❌

【开头】打破认知 / 引起好奇
        "做了3年护肤我才明白…"

【正文】
知识点1（分段写清楚）
知识点2
知识点3

每个知识点：
→ 错误做法
→ 正确做法
→ 为什么

【总结】
核心结论一句话
→ "简单来说就是…"

【标签】
#知识分享 #护肤干货 #新手必看
```

## 🎭 标题公式库

| 类型 | 公式 | 例子 |
|------|------|------|
| 数字型 | 数字 + 名词 + 效果 | 5件提升幸福感的居家好物 |
| 痛点型 | 痛点 + 解决方案 | 敏感肌救星！用了就回不去的面霜 |
| 对比型 | 以前vs现在 | 以前觉得贵，现在觉得值 |
| 时间型 | 天数/年数 + 效果 | 坚持30天早睡，我的变化 |
| 情绪型 | 场景 + 情绪表达 | 谁懂啊这杯咖啡的含金量 |
| 直接型 | 结论 + 理由 | 这家店我可以吃一百次 |

---

## 📝 写作检查清单

- [ ] 标题够不够抓人？有没有数字/情绪？
- [ ] 开头能不能 3 秒吸引住？
- [ ] 段落够不够短？（每段≤3行）
- [ ] Emoji 用到位了吗？（每段1-2个）
- [ ] 有没有"真实的缺点"或"注意事项"？
- [ ] 结尾有"互动引导"吗？（问问题/求推荐）
- [ ] 标签够不够精准？
- [ ] 整体读起来像不像"朋友在分享"？

---

> 以上模板不是死规矩，小红书文案的灵魂是"真实感"。
> 用好模板，但别忘了加入自己的语气和个性。
