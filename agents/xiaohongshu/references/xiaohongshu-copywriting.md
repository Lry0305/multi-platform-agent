# 小红书文案体系 (小红专用)

> 本指南定义了小红输出文案的风格、结构和模板。
> 所有产出遵循"先读此文，再写文案"原则。

---

## 🎯 核心原则

- **真实感第一** — 像朋友在分享，不是品牌在广告
- **第一人称** — "我"的视角，"我"的体验
- **短句+分段** — 每段不超过 3 行，留白多
- **Emoji 点缀** — 每段 1-2 个，不泛滥
- **数字说话** — 价格、数量、时间，越具体越好

---

## 📐 内容结构模板

### 1. 好物推荐 / 测评类

```
【标题】数字 + 场景 + 效果
        例：用了30天的xx，皮肤真的会说话

【开头】痛点引入 / 场景代入
        "作为一个xx星人，我一直在找…"
        "谁懂啊！这个xx真的绝了…"

【正文】
📦 开箱/第一印象
→ 外观、质感、味道、第一感受

✨ 使用体验（分段写）
→ 每次用都是什么感受
→ 和之前用的对比
→ 意想不到的惊喜点

⚠️ 缺点/注意事项
→ 诚实说问题，增加信任感

【总结】
✅ 什么人适合
✅ 什么场景最好用
✅ 性价比评价

【标签】
#好物推荐 #真实测评 #xx推荐
```

### 2. 探店打卡类

```
【标题】地点 + 亮点 + 推荐理由
        例：藏在胡同里的神仙咖啡馆 ☕

【开头】怎么发现的 / 第一印象
        "路过的时候被门头吸引了…"
        "朋友强推了N次终于来了…"

【正文】
📍 位置和环境
→ 好找吗？氛围怎么样？
→ 适合什么时候来？

🍽️ 点单推荐
→ 点了什么、多少钱
→ 哪个最好吃/最好喝
→ 避雷指南

📸 拍照攻略
→ 哪个角度最好拍
→ 什么时间光线最好

【总结】
🏆 整体评分 / 推荐指数
💰 人均消费
📌 地址 + 营业时间

【标签】
#探店 #xx探店 #周末去哪儿
```

### 3. 日常分享 / Vlog 类

```
【标题】时间 + 活动 + 情绪
        例：周末宅家的一天，治愈到我想哭 🥹

【开头】氛围铺垫
        "最近的天气太适合…"
        "分享一个让我心情变好的小事…"

【正文】
按时间线/活动线串起来
→ 早上干了什么
→ 中午的小确幸
→ 晚上的放松时刻

穿插：
→ 好物种草
→ 心情记录
→ 拍照分享

【结尾】
暖心的总结 + 互动
"你们最近有类似的治愈时刻吗？"

【标签】
#日常 #生活记录 #治愈系
```

### 4. 知识科普 / 教程类

```
【标题】数字 + 知识 + 目标人群
        例：新手必看的5个护肤误区 ❌

【开头】打破认知 / 引起好奇
        "做了3年护肤我才明白…"

【正文】
知识点1（分段写清楚）
知识点2
知识点3

每个知识点：
→ 错误做法
→ 正确做法
→ 为什么

【总结】
核心结论一句话
→ "简单来说就是…"

【标签】
#知识分享 #护肤干货 #新手必看
```

## 🎭 标题公式库

| 类型 | 公式 | 例子 |
|------|------|------|
| 数字型 | 数字 + 名词 + 效果 | 5件提升幸福感的居家好物 |
| 痛点型 | 痛点 + 解决方案 | 敏感肌救星！用了就回不去的面霜 |
| 对比型 | 以前vs现在 | 以前觉得贵，现在觉得值 |
| 时间型 | 天数/年数 + 效果 | 坚持30天早睡，我的变化 |
| 情绪型 | 场景 + 情绪表达 | 谁懂啊这杯咖啡的含金量 |
| 直接型 | 结论 + 理由 | 这家店我可以吃一百次 |

## 📝 写作检查清单

- [ ] 标题够不够抓人？有没有数字/情绪？
- [ ] 开头能不能 3 秒吸引住？
- [ ] 段落够不够短？（每段≤3行）
- [ ] Emoji 用到位了吗？（每段1-2个）
- [ ] 有没有"真实的缺点"或"注意事项"？
- [ ] 结尾有"互动引导"吗？（问问题/求推荐）
- [ ] 标签够不够精准？
- [ ] 整体读起来像不像"朋友在分享"？

> 用好模板，但别忘了加入自己的语气和个性。

## 🚀 新增：爆款写作结构（共11种）

### 5. 测评对比型

```
【标题】A vs B + 维度 + 结论
        例：兰蔻 vs 欧莱雅，30天实测对比 🧪

【开头】为什么做这个对比
        "两款都用了才敢说…"
        "被问爆了的对比来了…"

【正文】
📌 对比维度1：价格
→ 各自多少钱，性价比如何

📌 对比维度2：质地/使用感
→ 推开度、吸收度、肤感

📌 对比维度3：效果
→ 用了多久看到效果
→ 各自适合什么肤质

【总结】
🏆 各自优缺点
✅ 什么情况选A，什么情况选B
💰 预算建议

【标签】
#测评 #好物对比 #真实测评
```

### 6. 合集盘点型

```
【标题】数字 + 主题 + 亮点
        例：2024年我最爱的8件居家好物 🏠

【开头】引出合集
        "不知不觉攒了这么多…"
        "年度爱用！每一件都是心头好…"

【正文】
逐一介绍，每件按统一结构：
→ ① 名称 + 价格
→ ② 为什么买它
→ ③ 使用感受
→ ④ 推荐指数 ★★★★☆

【结尾】
"你们还有什么推荐的？评论区告诉我～"

【标签】
#合集 #年度爱用 #好物分享
```

### 7. 踩雷吐槽型

```
【标题】踩雷+后悔+原因
        例：花了大价钱买的xx，后悔死了 😤

【开头】为什么买
        "被种草了很久，终于下手了…"
        "跟风入的，结果…"

【正文】（诚实吐槽，有理有据）
❌ 槽点1：跟宣传不符
→ 具体哪里不一样

❌ 槽点2：性价比低
→ 多少钱，值不值

❌ 槽点3：使用感差
→ 哪里不好用

【总结】
⚠️ 什么人千万别买
🟢 有没有平替推荐

【标签】
#踩雷 #拔草 #劝退 #理性消费
```

### 8. 教程步骤型

```
【标题】步骤 + 效果 + 时长
        例：3步搞定ins风早餐摆盘 📸

【开头】成果展示 / 痛点
        "每次看别人发的美图都很羡慕…"
        "其实只要3步…"

【正文】
🛠️ 准备材料
→ 需要什么、哪里买、多少钱

📝 Step 1：xxx
→ 具体怎么做

📝 Step 2：xxx
→ 具体怎么做

📝 Step 3：xxx
→ 完成！效果展示

💡 小贴士
→ 容易踩的坑
→ 进阶玩法

【标签】
#教程 #手工DIY #生活技巧
```

### 9. 开箱体验型

```
【标题】开箱 + 产品 + 第一印象
        例：期待了一个月的快递终于到了！📦

【开头】购买动机
        "蹲了好久终于抢到了…"
        "朋友送的生日礼物，拆开瞬间…"

【正文】
📦 开箱过程
→ 包装怎么样
→ 第一眼印象

✨ 细节展示
→ 每个配件/部分的感受
→ 质感、做工、颜色

🤔 第一印象评分
→ 和预期对比

【结尾】
"再用一段时间来反馈效果～"

【标签】
#开箱 #购物分享 #快递开箱
```

### 10. 问答答疑型

```
【标题】常见问题 + 解答
        例：关于xx你们问得最多的10个问题 🙋

【开头】引出
        "上次发了之后收到好多私信…"
        "统一回答一下问得最多的问题…"

【正文】
Q1：xxx？
A1：xxx

Q2：xxx？
A2：xxx

…（5-10个问题）

【总结】
"还有问题评论区留言，我继续更新～"

【标签】
#答疑 #经验分享 #干货
```

### 11. 情绪故事型

```
【标题】情绪 + 故事 + 感悟
        例：28岁我才明白的事 🌙

【开头】情绪引入
        "最近突然想明白了一件事…"
        "以前的我一定想不到…"

【正文】
故事线展开
→ 背景（以前是什么样的）
→ 转折（发生了什么）
→ 现在（改变了什么）

穿插感悟
→ 具体例子
→ 为什么重要

【结尾】
温暖的总结 + 互动
"你们也有类似的时刻吗？"

【标签】
#人生感悟 #成长 #情绪日记
```

## 🎨 排版风格选项

> 选择不同排版风格，适配不同内容类型

| 风格 | 特点 | 适合内容 |
|------|------|---------|
| **简洁风** 😊 | 短段落，干净留白，emoji点缀 | 所有类型（默认） |
| **聊天风** 💬 | 像发微信，短句碎片化，多用语气词 | 日常分享、Vlog |
| **重点加粗风** 🔥 | 关键句**加粗**，引导视线，**核心结论**突出 | 教程、科普、干货 |
| **日记风** 📔 | 开头带日期，结尾带小尾巴 | 日常、情绪、旅行 |

### 简洁风（默认）
```
段落1

段落2

段落3
```

### 聊天风
```
段落1

对！就是这种感觉

段落2

真的真的强烈安利
```

### 重点加粗风
```
**核心结论：** 段落1

要点1：具体内容

**要点2：** 具体内容

总结：**一句话记住它**
```

### 日记风
```
📅 2024.xx.xx

段落1

段落2

—— 今天也要开心呀 ✨
```
